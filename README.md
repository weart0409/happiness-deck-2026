# 🏢 직장인의 행복 (Happiness at Work) - HTML 슬라이드덱 프로젝트

이 프로젝트는 **'직장인의 행복과 몰입'**을 주제로 한 대화형 HTML 슬라이드덱을 만들고, 다양한 학술·통계·사례 레퍼런스를 체계적으로 관리하며 AI와 효과적으로 협업하기 위한 작업 공간입니다.

---

## 📁 폴더 구조 한눈에 보기

```text
work/
├── 📄 README.md                 # 프로젝트 개요 및 협업 가이드 (현재 파일)
│
├── 📂 docs/                     # [소통 & 기획] AI와 주고받을 기획 및 피드백 문서
│   ├── PROJECT_BRIEF.md         # 슬라이드 목적, 타겟 청중, 핵심 메시지, 톤앤매너
│   ├── OUTLINE.md               # 슬라이드 장표별 스토리라인 & 목차 설계도
│   └── FEEDBACK.md              # 수정 요청사항, 아이디어 메모, 다음 스텝
│
├── 📂 references/               # [레퍼런스 관리] 논문, 통계, 서적, 인터뷰 출처 체계
│   ├── REFERENCES.md            # 모든 출처의 마스터 인덱스 (REF-ID 부여)
│   ├── notes/                   # 주요 레퍼런스별 상세 요약 및 시사점 정리
│   │   └── REF-01_gallup_workplace_report.md
│   └── raw/                     # 참고할 PDF, 캡처 이미지, 원문 텍스트 저장소
│
└── 📂 src/                      # [슬라이드덱 소스코드] 실행 가능한 HTML/CSS/JS
    ├── index.html               # 메인 슬라이드덱 (브라우저로 바로 실행 가능)
    ├── css/
    │   └── custom.css           # 슬라이드 디자인, 한글 폰트, 레퍼런스 팝업 스타일
    ├── js/
    │   └── main.js              # 슬라이드 동작 및 레퍼런스 모달/툴팁 기능
    └── assets/                  # 이미지, 아이콘, 차트 등 시각 에셋
        └── images/
```

## 🤝 AI와 소통하는 법 (협업 가이드)

1. **아이디어나 수정 요청이 생겼을 때:**
   - 대화창에 편하게 말해주셔도 되고, `docs/FEEDBACK.md`에 적어둔 뒤 "피드백 반영해줘"라고 하셔도 됩니다.
2. **새로운 레퍼런스를 추가하고 싶을 때:**
   - 기사 링크나 책 내용, 통계 수치를 알려주시면 `references/REFERENCES.md`에 `[REF-XX]` 형태로 고유 번호를 매겨 슬라이드 각주와 자동 연결해드립니다.
3. **슬라이드 내용/순서를 바꾸고 싶을 때:**
   - `docs/OUTLINE.md`의 목차를 기준으로 "4번 장표의 내용을 ~로 바꿔줘"처럼 말씀해주시면 정확하게 수정됩니다.

## 🚀 슬라이드 실행 방법

- `src/index.html` 파일을 더블 클릭하여 크롬/엣지/웨일 등 웹 브라우저에서 바로 열 수 있습니다.
- 별도의 Node.js 설치나 빌드 과정 없이 동작하도록 가볍고 강력한 CDN 기반으로 세팅되어 있습니다.
- **슬라이드 조작 키:**
  - `Space` / `→` / `↓`: 다음 슬라이드
  - `←` / `↑`: 이전 슬라이드
  - `F`: 전체화면 모드
  - `ESC` / `O`: 전체 슬라이드 모아보기 (오버뷰)
  - `S`: 발표자 모드 (스피커 노트)
